```python
TOLERANCE = 1e-9   # float-noise guard for comparisons — NOT a risk limit (document it)
def known(value: object) -> float | None          # the value as a float when it is a real finite number (bool excluded), else None — NaN, ±inf and None are "unknown"
def exceeds(value: float, limit: float) -> bool   # value > limit beyond float noise: value - limit > TOLERANCE * max(1.0, abs(value), abs(limit)); math.inf exceeds every finite limit
def below(value: float, limit: float) -> bool     # exceeds(limit, value)
def money(value: float | None) -> str             # "$1,234.56", "-$1,234.56", "unlimited" for inf, "n/a" for None
def long_quantity(context, symbol: str) -> float | None
    # shares/contracts held LONG in exactly `symbol` (0.0 when none, or when the position there is short); None when context.positions is None or the matching position's qty is unknown.
    # Position.side is "long"/"short"; quantity = abs(qty).
def is_closing_sale(proposal, context) -> bool
    # True only for an EQUITY SELL whose quantity does not exceed long_quantity(context, proposal.proposal.symbol). Unknown positions → False.
def signed_limit(proposal) -> float | None
    # +limit_price for a buy (a debit paid), -limit_price for a sell (a credit / proceeds received); None for a market order or when limit_price is None / not finite / <= 0.
def mid_price(proposal, context) -> float | None
    # Equity: context.quote.mid, only when context.quote is for this proposal's symbol and bid and ask are known, positive and not crossed (ask >= bid); else None.
    # Option: the SIGNED net mid per proposal unit = Σ over legs of sign × (leg.quantity / proposal.quantity) × leg mid, sign +1 for buy legs, -1 for sell legs
    #   (positive = a debit structure, negative = a credit structure). The leg's quote is the OptionSnapshot in context.leg_quotes whose symbol equals leg.symbol.
    #   None when there are no legs, a leg has no snapshot, or a leg's bid/ask is unknown, negative or crossed (a 0.0 bid is valid for an option).
def worst_case_entry(proposal, context) -> float | None
    # The signed per-unit price a MARKET order could be filled at: equity buy → +ask; equity sell → -bid; option → Σ buy legs ask×ratio − Σ sell legs bid×ratio. None when a needed quote is missing.
def entry_price(proposal, context) -> float | None
    # signed_limit(proposal) for a limit order; worst_case_entry(proposal, context) for a market order.
def notional(proposal, context) -> float | None
    # Dollars the proposal commits; None = cannot be computed (callers reject).
    # Equity: quantity × abs(entry_price).
    # Option bought (side buy — a debit): entry_price × contract_multiplier × quantity; None if entry_price is not positive (a "debit" that is really a credit is inconsistent).
    # Option sold (side sell — a credit): the structure's max loss: context.analysis.max_loss; math.inf when context.analysis.unlimited_risk (or max_loss is None); None when context.analysis is None.
def exposure(context, underlying: str) -> float | None
    # Dollars already committed to `underlying`: Σ abs(market_value) of positions whose underlying_of(symbol) == underlying (abs(qty) × current_price when market_value is unknown; None if neither is known)
    # + Σ over open orders on that underlying of quantity × limit_price (× contract_multiplier when the order symbol is an OCC option symbol); an open order without a limit price cannot be valued → None.
    # None when context.positions is None. 0.0 when nothing is held or pending.
def held_underlyings(context) -> frozenset[str] | None
    # underlying_of(symbol) for every position and every open order; None when context.positions is None.
def daily_loss_cap(context) -> float | None
    # limits.daily_loss_limit_pct / 100 × start_of_day_equity as a positive dollar amount; None when start_of_day_equity is unknown or <= 0.
def leg_dte(leg, context) -> int                  # (leg.expiration - context.market_date).days  (0 = expires today, negative = expired)
def structure_problems(proposal) -> tuple[str, ...]
    # Why an OPTION proposal's legs cannot be analysed as one structure (empty tuple = sound; always empty for an equity):
    # no legs; legs on more than one underlying; the proposal symbol's underlying differs from the legs'; legs with different expirations; a leg quantity that is not a whole number of contracts.
```
A helper `is_occ(symbol) -> bool` (via `parse_occ_symbol`) is fine. Every function treats NaN/inf inputs as unknown via `known` (the only place inf is produced deliberately is `notional` for unlimited risk).

## §4 aegis/policy/rules.py — the twenty rules (stage "rules")
```python
Rule = Callable[[ProposalUnderReview, PolicyContext], RuleResult]
RULES: tuple[Rule, ...]          # the twenty functions below, in THIS order
RULE_NAMES: tuple[str, ...]      # tuple(rule.__name__ for rule in RULES) — each function is named exactly as its rule
def account_rules(context) -> tuple[RuleResult, ...]   # the five proposal-independent results (kill_switch, halted, market_hours, daily_loss_limit, max_daily_trades), in that order — what the limits report shows as blocked_by. The five registered rules return exactly these results.
```
Same import allowlist as measures.py (plus `aegis.policy.measures`). Each rule is a pure function returning ONE RuleResult whose `name` is the rule's name and whose `detail` states the numbers compared (use `money()`), the config key in parentheses where a limit applies (e.g. "(risk_limits.max_position_pct)"), or exactly what is missing. Comparisons use `exceeds` / `below` so float noise never flips a boundary. UNKNOWN IS NEVER GOOD NEWS: where a rule needs a value the context does not have, it REJECTs and says what is missing — except the two tier rules (short_sale, auto_tier), which ESCALATE on unknowns as specified below. A rule never raises for any input a valid ProposalUnderReview/PolicyContext can hold.
1. `kill_switch` — REJECT when `context.controls.kill_switch`. PASS otherwise.
2. `halted` — REJECT when `context.controls.halt_unknown` (cannot prove trading is not halted) or `halt_until` is not None and `halt_until > context.now`. PASS when there is no halt or it has expired (`halt_until <= now`).
3. `market_hours` — REJECT when `context.clock` is None (cannot confirm the market is open); when `not clock.is_open`; or when the clock says open but `clock.next_close` is not None and `context.now >= clock.next_close` (a stale clock). PASS otherwise.
4. `daily_loss_limit` — pnl = known(context.daily_pnl); cap = daily_loss_cap(context). Either unknown → REJECT ("cannot evaluate …"), with NO halt_until. Tripped when pnl <= -cap (i.e. `not exceeds(pnl, -cap)`): REJECT with `halt_until` = `clock.next_open` when the clock has one that is `> now`, else `now + timedelta(hours=limits.halt_fallback_hours)`; the detail names the P&L, the cap, the percentage and the halt instant. PASS otherwise, with the headroom (pnl + cap) in the detail.
5. `no_trade_list` — REJECT when any of `proposal.underlyings` or `proposal.symbols` is in `limits.no_trade_list`.
6. `watchlist_only` — when `limits.watchlist_only`: REJECT when any of `proposal.underlyings` is not in `context.watchlist`. Disabled → PASS (say it is disabled).
7. `invalidation_present` — REJECT when `proposal.proposal.invalidation.strip()` is empty.
8. `buying_power` — a closing sale (`is_closing_sale`) → PASS (it consumes none). Otherwise available = `context.buying_power` for an equity; for an option `context.options_buying_power` when known, else `min(buying_power, cash)` when both are known, else unknown. REJECT when the notional or the available figure is unknown, or `exceeds(notional, available)`.
9. `max_position_pct` — a closing sale → PASS. cap = max_position_pct / 100 × equity. REJECT when equity is unknown or <= 0, the notional is unknown, `exposure(context, proposal.underlying)` is unknown, or `exceeds(notional + exposure, cap)`.
10. `max_open_positions` — positions are counted as DISTINCT UNDERLYINGS held or pending (`held_underlyings`). Unknown → REJECT. A closing sale → PASS. A proposal whose underlying is already in the set → PASS (it adds no position). Otherwise REJECT when `len(held) >= limits.max_open_positions`.
11. `max_daily_trades` — REJECT when `context.orders_today >= limits.max_daily_trades`.
12. `duplicate` — REJECT when (a) another proposal in `context.recent_proposals` (different id) has the same symbol, instrument and side and was created at most `duplicate_window_minutes` BEFORE this proposal (0 <= this.created_at − other.created_at <= window; on an exact tie the one with the smaller id is the earlier), or (b) any order in `context.open_orders` has a symbol in `proposal.symbols`. The detail names the other proposal / order. (Only an EARLIER proposal makes this one a duplicate, so two proposals never reject each other.)
13. `limit_price_sanity` — market order: REJECT unless `limits.allow_market_orders` (then PASS). Limit order: REJECT when `signed_limit` is None (no usable limit price); when `mid_price` is None (no current mid — say for which symbol/leg); for an option when abs(mid) <= TOLERANCE; or when the deviation exceeds `limit_price_tolerance_pct`, where deviation% = abs(limit_price − mid) / mid × 100 for an equity and abs(signed_limit − net_mid) / abs(net_mid) × 100 for an option (signed, so a credit mislabelled as a debit is ~200% away).
14. `options_min_dte` — equity → PASS ("not an option"). Option with no legs → REJECT. REJECT when any leg's `leg_dte` < `limits.min_dte` (list the legs and their DTE).
15. `options_max_loss` — equity → PASS. Option: REJECT when `structure_problems` is non-empty (list them); when `context.analysis` is None; when `analysis.unlimited_risk` (unconditionally — say so) or `analysis.max_loss` is None/not finite; or when `exceeds(max_loss, limits.max_loss_per_trade)`.
16. `options_max_contracts` — equity → PASS. Option with no legs → REJECT. REJECT when any leg's quantity exceeds `limits.max_contracts`.
17. `options_escalate` — option → ESCALATE, always. Equity → PASS.
18. `short_sale` — only an EQUITY SELL is examined: a closing sale → PASS; otherwise (a short sale, or positions unknown so it cannot be shown to close a long) → REJECT when `limits.reject_short_sales` else ESCALATE. Everything else → PASS.
19. `min_confidence` — FLAG when `below(confidence, limits.min_confidence)`. PASS otherwise.
20. `auto_tier` — PASS only when ALL hold: `limits.auto_execute.enabled`; the instrument is equity; the side is buy, or it is a closing sale; the order type is limit; `proposal.underlying` is in `context.watchlist`; the notional is known and does not exceed `limits.auto_execute.max_notional`. Otherwise ESCALATE, listing every unmet criterion.

## §5 aegis/policy/engine.py (stage "engine")
```python
def run_rules(proposal, context, rules: Sequence[Rule] = RULES) -> tuple[RuleResult, ...]
    # Runs EVERY rule, in order, never short-circuiting. A rule that raises, returns something that is not a RuleResult, or returns a result under another name
    # yields RuleResult(name=<rule name>, outcome=REJECT, detail="rule failed: <Type>: <message>") — the engine fails closed and still runs the rest.
def resolve_verdict(results: Sequence[RuleResult], expected: Sequence[str] = RULE_NAMES) -> tuple[Verdict, str | None]
    # Precedence: any REJECT → (REJECT, name of the FIRST rejecting result); else any FLAG → (FLAG_ONLY, None); else any ESCALATE → (NEEDS_APPROVAL, None); else (AUTO_EXECUTE, None).
    # Integrity guard, checked FIRST: unless the result names equal `expected` exactly (same rules, same order, none missing, none repeated) the verdict is (REJECT, "engine_integrity").
    # AUTO_EXECUTE is therefore reachable only when all twenty registered rules ran and every one of them — auto_tier included — returned PASS.
def decide(proposal, context) -> Evaluation
    # Pure: run_rules + resolve_verdict; decided_at = context.now; halt_until = the daily_loss_limit result's halt_until when it is set AND
    # (context.controls.halt_until is None or context.controls.halt_until < that instant); else None.
def evaluate(proposal, context, conn, *, dry_run: bool = False) -> PolicyDecision
    # decide(), then build the store PolicyDecision(proposal_id, decided_at=context.now, verdict, rules_evaluated=evaluation.rules_evaluated, failing_rule, notes=<one-line summary: verdict, the non-PASS rule names by outcome>).
    # dry_run → return it unsaved; write NOTHING (no decision, no event, no halt).
    # Otherwise, in this order: (1) if evaluation.halt_until: repo.set_halt_until(conn, evaluation.halt_until, now=context.now, event=<Event kind "risk_limit_tripped", level CRITICAL, occurred_at context.now,
    #     payload {"rule": "daily_loss_limit", "proposal_id", "daily_pnl", "start_of_day_equity", "daily_loss_limit_pct", "cap", "halt_until" (ISO)}>);
    # (2) repo.record_decision(conn, decision, event=<for a verdict other than AUTO_EXECUTE: Event kind "policy_reject" | "policy_flag_only" | "policy_needs_approval", level WARNING for REJECT else INFO, occurred_at context.now,
    #     payload {"proposal_id", "decision_id", "verdict", "failing_rule", "symbol", "non_pass": [{"rule","outcome","detail"}, …]}>; None for AUTO_EXECUTE) — called EXACTLY ONCE per non-dry evaluation.
    # Returns the decision as stored. StoreError propagates (nothing is swallowed).
```
Import `record_decision` and `set_halt_until` at module level from `aegis.store.repo` (tests monkeypatch `aegis.policy.engine.record_decision`). engine.py reads no clock (`context.now` only), no config, no network. def structure_analysis(proposal, *, entry_price: float | None, contract_multiplier: int) -> PositionSummary | None
```python
    # Pure. None for an equity, when structure_problems(proposal) is non-empty, when entry_price is unknown, or when the pricing engine raises PricingError.
    # Builds one aegis.pricing OptionLeg per ProposalLeg (BUY → Side.LONG, SELL → Side.SHORT, quantity int(leg.quantity)); the net premium is the proposal's price, not the leg mids: total = entry_price × proposal.quantity
    # per-share dollars to distribute, placed entirely on ONE leg (premium must be >= 0): the first BUY leg when entry_price >= 0 (premium = entry_price × proposal.quantity / leg.quantity), the first SELL leg when it is negative
    # (premium = abs(entry_price) × proposal.quantity / leg.quantity); every other leg gets premium 0.0; no leg of the needed side → None. The expiry payoff depends only on the net premium, so this is exact.
    # Sanity: the returned summary's net_premium must equal entry_price × proposal.quantity × contract_multiplier within tolerance, else None.
def build_context(conn, proposal: ProposalUnderReview | None = None, *, config: AegisConfig | None = None, now: datetime | None = None) -> PolicyContext
```
`build_context`: config = config or get_config(); now = now or utcnow() (naive → UTC); market_date = the date of `now` in ZoneInfo(config.pricing.expiry_timezone). From the STORE (a StoreError propagates — without the store nothing can be recorded anyway): `get_controls`; `get_open_orders`; `count_orders_submitted_between(start, end)` for the exchange-local day of market_date ([00:00 local, next 00:00 local) converted to UTC); `get_proposals_since(min(now, proposal.created_at) − duplicate_window)` minus the proposal itself (with no proposal: since now − window). From the DATA LAYER, each call guarded — a DataError/ConfigError never aborts the build, it leaves the fields None and appends "<what>: <error>" to `errors`: `get_market_clock()`; `get_account_state()` → equity, cash, buying_power, options_buying_power, start_of_day_equity = last_equity, daily_pnl = equity − last_equity when both are known, positions = tuple(state.positions); with a proposal: equity → `get_spot(symbol)` as `quote`; option → for each distinct (underlying_of(leg.symbol), leg.expiration) one `get_option_chain(underlying, expiration)`, and the leg's `OptionSnapshot` by symbol into `leg_quotes` (a leg not in its chain → an `errors` line). Then `analysis = structure_analysis(proposal, entry_price=measures.entry_price(proposal, <the context so far>), contract_multiplier=config.pricing.contract_multiplier)`. limits = config.risk_limits; watchlist = tuple(config.watchlist); contract_multiplier from config.pricing. Import the fetchers at module level (`from aegis.data.market import get_market_clock, get_option_chain, get_spot`, `from aegis.data.account import get_account_state`) so tests monkeypatch `aegis.policy.context.get_spot` etc. Never import `aegis.data.clients`, `aegis.data.news` or `alpaca`.

## §8 aegis/cli/policy.py (stage "cli")
```
python -m aegis.cli.policy evaluate (PROPOSAL_ID | --latest) [--dry-run] [--db PATH]
python -m aegis.cli.policy kill {on,off,status} [--db PATH]
python -m aegis.cli.policy limits [--db PATH]
```
`main(argv=None, *, context_builder: ContextBuilder | None = None) -> int` (default `build_context`; tests inject a builder returning a hand-made context, called as `builder(conn, proposal, config=config)` / `builder(conn, config=config)`). Shape and error handling exactly like aegis/cli/brain.py: a bad command line is one line on stderr and exit 1 (reuse the same `_Parser`/`_UsageError` idea, re-implemented locally — do not import private names from another CLI); ConfigError/StoreError/PolicyError → "policy <command> failed: …" on stderr, exit 1; KeyboardInterrupt → 130; anything else → "(unexpected): Type: message", exit 1. Every string taken from the store or a rule detail is printed on one line with control characters removed. `--db` as in the other CLIs (`:memory:` handled the same way).
- `evaluate`: exactly one of PROPOSAL_ID / `--latest` (both or neither is a usage error). The database must exist (never create one to evaluate). Non-dry: `open_store`; `--dry-run`: `connect` and refuse a database with pending migrations ("run `python -m aegis.cli.db init`"), write nothing. `--latest` with no undecided proposal → "no proposal without a decision" on stderr, exit 1. Unknown id → clean error, exit 1. Prints: the proposal header (id, created, symbol (instrument), "buy 4 limit @ 2.40", confidence, legs); `verdict: <VERDICT>` and, for REJECT, `failing rule: <name>`; "decision <id> recorded" or "DRY RUN — nothing was written"; if the evaluation set a halt: "trading HALTED until <ts>"; then `rules (20)` — one line per rule: index, name, outcome, detail, in registry order; then a `context` block: as-of time, market open/closed (next open/close), kill switch, halt, equity, start-of-day equity, today's P&L, buying power, options buying power, positions/open orders/orders today counts, and every line of `context.errors` under "data problems". Exit 0 whenever a verdict was produced (whatever it is).
- `kill on|off`: `open_store`, `set_kill_switch(conn, on, event=Event(kind="kill_switch", level WARNING for on / INFO for off, message, payload {"state": "on"|"off", "previous": "on"|"off", "source": "cli"}))` — logged even when the state does not change; prints the new state. `kill status`: `connect` (never creates or migrates; a missing database or pending migrations is a clean error, exit 1); prints the kill switch state and when it was last set, the halt (none / until <ts> (active) / expired at <ts> / UNKNOWN), and every line of `controls.problems`. Exit 0.
- `limits`: `connect` (as `kill status`), `builder(conn, config=config)`, `limits_report(context)`, printed as: as-of + market state; kill switch and halt state; "trading blocked by: <rule names>" or "no account-level block"; a table of each `LimitLine` (name, limit, used, headroom — USD with money formatting, counts as integers) with BREACHED marked; each `ExposureLine`; the auto-execute tier; "data problems" lines. Exit 0. The function `limits_report` is the single source — the CLI only formats (the Phase 8 dashboard will call the same function).
